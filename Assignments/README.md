Week 3 – IoT Assignments

Overview

This repository contains the Week 3 Internet of Things (IoT) assignments completed as part of the Skill Nexus training program.

Topics Covered

- ESP32 microcontroller programming using Wokwi.
- Wi-Fi connectivity using ESP32.
- Temperature and humidity monitoring using the DHT22 sensor.
- Cloud data transmission using ThingSpeak.
- IoT dashboard creation and remote monitoring.
- MQTT communication using Publisher, Subscriber and Broker concepts.

Tools and Technologies

- ESP32
- DHT22 Sensor
- Arduino IDE / Wokwi Simulator
- ThingSpeak Cloud Platform
- MQTT Protocol
- HiveMQ MQTT Broker
- Embedded C / C++

Outcome

Successfully completed the Week 3 IoT practical assignments, covering sensor interfacing, wireless communication, cloud integration and remote monitoring.
